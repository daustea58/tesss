# Gallery photos

Add up to eight original photos here, then update each `src` value in `src/data/siteConfig.js`.

Example:

```js
{ id: 1, src: '/assets/images/gallery/our-first-photo.jpg', caption: 'My favorite human ♡' }
```

The website keeps real photos in their original rendering style; only the scrapbook frame, tape, stickers, and controls are pixel-art.
